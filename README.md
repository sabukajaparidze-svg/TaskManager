# Task Manager

A simple command-line Task Manager built with C++.

## Features

- Add tasks
- View tasks
- Complete tasks
- Delete tasks
- Save tasks to a file
- Load tasks when the program starts
- Supports task names with spaces

## Technologies

- C++
- STL
- Vector
- File I/O
- Git & GitHub

## How to Run

Compile the program:

```bash
g++ main.cpp -o TaskManager
